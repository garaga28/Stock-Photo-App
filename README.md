# Stock Photo App

A full-stack photo sharing application built using:

- Java
- Spring Boot
- React
- MySQL
- JWT Authentication
- Razorpay Payment Gateway

## Features

- User Registration with OTP
- Login Authentication
- Upload Photos
- Premium Photos
- Razorpay Payments
- Download Photos
- Delete Own Photos
- Forgot Password with OTP

## Tech Stack

Backend:
- Spring Boot
- Spring Security
- JPA/Hibernate
- MySQL

Frontend:
- React
- Axios
- React Router

Database:
- MySQL
